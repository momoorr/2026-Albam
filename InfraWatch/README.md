## 알밤(Albam)

## 무인매장 IT 인프라 장애 대응 및 자동복구 시스템

---

### 1. 프로젝트 주제

**무인매장 IT 인프라 장애 대응 및 자동복구 시스템**

무인매장에서 운영되는 POS, DB, 재고 관리 등의 IT 인프라를 중앙에서 모니터링하고, 장애 발생 시 자동으로 감지 및 복구하는 클라우드 기반 인프라 관리 시스템



### 2. 프로젝트 목적

무인매장은 관리자가 항상 현장에 상주하지 않기 때문에 서버나 서비스에 장애가 발생했을 때 즉각적으로 대응하기 어렵다는 문제가 있다.

본 프로젝트는 이러한 문제를 해결하기 위해 무인매장의 주요 IT 인프라 상태를 중앙에서 확인하고, 장애 발생 시 이를 자동으로 감지하여 복구할 수 있는 시스템을 구축하는 것을 목적으로 한다.

단순한 서버 모니터링에 그치지 않고,

**상태 확인 → 장애 감지 → 장애 대응 → 자동 복구 → 결과 기록**

의 과정을 자동화하는 것을 목표로 한다.



### 3. 프로젝트 시나리오

가상의 무인매장을 대상으로 IT 인프라 환경을 구성한다.

무인매장에서는 다음과 같은 시스템이 운영되고 있다고 가정한다.

```text

무인매장
│
├── POS 서버
│   └── 주문 및 결제 서비스
│
├── DB 서버
│   └── 매장 데이터 저장
│
└── 재고 관리 서버
    └── 상품 및 재고 관리

```

### 4. 핵심 기능
### 4.1 인프라 상태 모니터링

각 서버와 서비스의 상태를 주기적으로 확인한다.

* 서버 연결 상태 확인
* CPU 사용량 확인
* 메모리 사용량 확인
* 디스크 사용량 확인
* 서비스 상태 확인
* 포트 상태 확인
* 마지막 점검 시간 표시

### 4.2 장애 감지
서버 또는 서비스에 문제가 발생하면 자동으로 장애를 감지한다.

```text

정상 상태
    ↓
Health Check
    ↓
응답 없음 / 서비스 중단
    ↓
장애 감지
    ↓
장애 상태 표시

```

### 4.3 장애 자동 복구
자동으로 복구할 수 있는 장애가 발생하면 복구 작업을 수행한다.

```text

서비스 장애
    ↓
장애 감지
    ↓
복구 명령 실행
    ↓
서비스 재시작
    ↓
Health Check
    ↓
정상 여부 확인

```

### 4.4 장애 이력 관리
장애가 발생한 시간과 복구 과정을 기록한다.

```text

[14:32:01] POS 서버 장애 발생
[14:32:03] 장애 감지
[14:32:04] 자동 복구 시작
[14:32:06] 서비스 정상화

```

관리자는 과거에 발생한 장애와 복구 결과를 확인할 수 있다.

### 7. 장애 대응 시나리오
**Scenario 1. 정상 상태**
모든 서버와 서비스가 정상적으로 동작한다.

```text

POS 서버       🟢 정상
DB 서버        🟢 정상
재고 서버      🟢 정상
      
```

**Scenario 2. POS 서비스 장애 발생**
테스트를 위해 POS 서비스를 의도적으로 중지하여 장애 상황을 만든다.

```text

POS 서버       🔴 장애
DB 서버        🟢 정상
재고 서버      🟢 정상
      
```

**Scenario 3. 장애 감지**
Python 기반 모니터링 시스템이 POS 서비스의 상태를 확인하고 장애를 감지한다.

```text

POS 서비스 응답 없음
        ↓
Health Check 실패
        ↓
장애 상태 확인
        ↓
장애 이력 기록
      
```

**Scenario 4. 자동 복구**
시스템이 장애가 발생한 서비스를 자동으로 재시작한다.

```text

장애 감지
    ↓
복구 명령 실행
    ↓
서비스 재시작
    ↓
Health Check
    ↓
정상 응답 확인
      
```

**Scenario 5. 복구 완료**
서비스가 정상적으로 복구되면 대시보드의 상태를 업데이트한다.

```text

POS 서버       🟢 정상
DB 서버        🟢 정상
재고 서버      🟢 정상
      
```

### 9. 프로젝트 목표
최종적으로 다음과 같은 환경을 구현하는 것을 목표로 한다.

무인매장의 서버 및 서비스에 장애가 발생하면 관리자가 직접 서버에 접속하지 않아도 장애를 감지하고, 자동으로 복구 가능한 장애는 복구하며, 장애 발생부터 복구까지의 모든 과정을 기록하는 클라우드 기반 IT 인프라 관리 시스템 구축

최종 발표에서는 실제 장애 상황을 의도적으로 발생시킨 후,

```text

정상 상태
    ↓
장애 발생
    ↓
장애 감지
    ↓
자동 복구
    ↓
정상 상태 회복
    ↓
장애 이력 확인

```
